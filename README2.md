# tehran_house-market-analysis

تحلیل آگهی‌های فروش آپارتمان در تهران بر اساس داده‌های دیوار (۲۰۲۱ و ۲۰۲۳).

## هدف پروژه

مقایسه رشد قیمت مناطق مختلف تهران و پیدا کردن بهترین مناطق برای خرید با بودجه‌های مختلف.

## پیشرفت تا الان

- [x] بارگذاری دیتاست ۲۰۲۳ (~۹۴ هزار آگهی)
- [x] تبدیل قیمت از متن فارسی به عدد و محاسبه آمار اولیه
- [x] تمیز کردن دیتاست ۲۰۲۱ (JSON)
- [x] مقایسه رشد قیمت مناطق

## نتایج کلیدی

- میانه‌ی رشد قیمت هر متر مربع در تهران بین سال‌های ۱۴۰۰ و ۱۴۰۲ حدود **۱۴۶٪** بوده است.
- مناطقی مانند ابن‌بابویه، مولوی و شهرک کوهسار بیشترین رشد قیمت (~۲۰۰٪+) را داشته‌اند.
- مناطق گران‌قیمت شمالی مانند شهرک غرب، فرمانیه و نیاوران رشد کندتری (~۹۵-۹۹٪) نسبت به میانگین شهر داشته‌اند.

## ساختار پروژه

```
tehran_house-market-analysis/
├── README.md
├── first_look1.ipynb              # بررسی اولیه دیتاست ۲۰۲۳
├── Housing_Analysis_2021_2023.ipynb  # نوت‌بوک کامل: تمیزکاری + مقایسه‌ی رشد قیمت
├── clean_2021.py                  # اسکریپت تمیزکاری دیتاست ۲۰۲۱
├── clean_2023.py                  # اسکریپت تمیزکاری دیتاست ۲۰۲۳
├── compare_growth.py              # اسکریپت مقایسه‌ی رشد قیمت مناطق
└── data/
    ├── Divar_2021.json            # داده‌ی خام ۲۰۲۱
    ├── Divar_2023.csv             # داده‌ی خام ۲۰۲۳
    ├── divar_2021_clean.csv       # داده‌ی تمیزشده‌ی ۲۰۲۱
    ├── divar_2023_clean.csv       # داده‌ی تمیزشده‌ی ۲۰۲۳
    └── neighborhood_growth.csv    # جدول رشد قیمت به تفکیک منطقه
```

## نحوه‌ی اجرا

```bash
python clean_2021.py
python clean_2023.py
python compare_growth.py
```

یا به‌صورت یکجا در `Housing_Analysis_2021_2023.ipynb`.
